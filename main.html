How Patchwork works

    
1
Load a page
Drop a .html file, paste code, or hit the demo. Open several pages at once — each gets its own tab with independent undo, history and change log.

    
2
Click text, type
Headings, paragraphs, buttons, links, list items, table cells — click it and type. Plain text only, so the layout never breaks. A live word and character count sits in the footer.

    
3
Point at anything
Script-written text isn't editable — but clicking it (or Alt+Click on anything) flashes the exact code line three times, then stops. Images, scripts and stylesheets also pop up an info bar with copy / open / swap-URL actions that stays until you move on.

    
4
Track, compare, export
The Changes log lists every edit (click one to jump to its line). Snapshot with History, review old-vs-new in the fullscreen Diff, use Replace-all for rebrands, and optionally re-indent whitespace on export.

Tip: click-to-locate searches id, class, attributes, then visible text — and finally scans the page's own JavaScript for the same tokens. Only a truly untraceable element falls back to a plain pane flash. External images/stylesheets load fine if they use full https URLs.
